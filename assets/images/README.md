# Images

Replace any file below with a same-named file to update the site — no code changes needed.
Any missing file falls back to a labelled block rather than breaking the layout.

## In use

| Filename | Used for |
|---|---|
| `product-dark.jpg` | The Diffuser section |
| `detail.jpg` | The Collection section |
| `gifting.jpg` | Gifting — the LUXE velvet pouch |
| `story.jpg` | Our Story |
| `og-image.jpg` | social share preview (1200x630) |

Photographs are graded cold and dim in CSS so they sit in a dark cabin rather than glowing
off it, and warm up on hover. That grade is in `.media img` in `styles.css` — if a
replacement photo looks too dark, change it there rather than re-editing the JPEG.

## Optional, not yet supplied

| Filename | Used for | Suggested size |
|---|---|---|
| `logo.png` | header logo — transparent PNG or SVG, light on dark | 400x140 |
| `favicon.png` | browser tab icon | 512x512 |

Without `logo.png` the header shows the LuxeScent wordmark set in Fraunces with UK beside
it. That is a deliberate fallback, not a broken image — if you like it, no logo file is
needed. Note that a logo drawn dark-on-light will disappear against this site; it needs to
be light on transparent.

## The scent cards have no photography

Each vessel is a drawn SVG, tinted per blend, not a photograph — cap, cord, oil level and
highlights. Nothing to supply, and it scales to any size for nothing.
