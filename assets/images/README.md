# Images

Drop files in this folder using **exactly** these names. Any file that is
missing shows a labelled dark placeholder instead — the site never breaks, so
you can add them one at a time.

| Filename | Used for | Suggested size |
|---|---|---|
| `logo.png` | header logo (transparent PNG/SVG, light-coloured) | 400×140 |
| `favicon.png` | browser tab icon | 512×512 |
| `hero.jpg` | full-bleed hero — diffuser hanging in a car interior | 2400×1400 |
| `product-clear.jpg` | clear-glass bottle, studio shot | 1200×1600 |
| `product-dark.jpg` | dark-glass bottle, studio shot | 1200×1600 |
| `story.jpg` | workshop / hands / packing shot | 1200×1600 |
| `og-image.jpg` | social share preview | 1200×630 |
| `scent-imperium.jpg` | Imperium | 1000×1250 |
| `scent-proventus.jpg` | Proventus | 1000×1250 |
| `scent-efferus.jpg` | Efferus | 1000×1250 |
| `scent-ciel-bleu.jpg` | Ciel Bleu | 1000×1250 |
| `scent-aurum.jpg` | Aurum | 1000×1250 |

**Tips**

- Shoot the nine scent cards on the *same* background at the *same* crop —
  the grid only looks premium if it looks like one set.
- Keep JPEGs under ~300 KB each (GitHub Pages has no image optimisation).
- If a filename must change, update it in the `SCENTS` array in
  `assets/js/main.js`.
